# NR3DS roadmap

## v0.001 - current

- portable physics core
- desktop tests + CSV simulation
- 3DS Citro2D driving front-end source

## v0.002

- extract Unity serialized RCC settings / curve keyframes
- replace temporary torque, turbo, gear and tire-temperature curves
- finish clutch-kick / burnout / drift state mapping
- explicit manual/automatic transmission modes

## v0.003

- Citro3D renderer
- one low-poly player car
- one looping highway segment
- fog and emissive-style night materials
- fixed 30 Hz physics / 30 FPS rendering target

## v0.004

- chunked highway streaming
- simple collision mesh
- 3-5 traffic cars
- traffic waypoint system

## v0.005

- opponent AI
- race checkpoints
- drafting/catch-up behavior as appropriate

## Later

- garage
- tuning
- progression
- audio/music streaming
- more roads/cars

## Performance rules

The Old 3DS remains the baseline. Features are only kept if they stay inside CPU, GPU and memory budgets on real hardware.
