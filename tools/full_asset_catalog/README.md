# Complete NIGHT-RUNNERS sharedassets catalog

Generated from the user-supplied four 7-Zip archives.

`all_sharedassets_catalog.json` contains per-file counts plus Mesh, Material and Texture2D names/path IDs for `sharedassets0.assets` through `sharedassets86.assets`.

`all_meshes.csv` is a compact mesh-only lookup table useful when matching scene MeshFilter PPtrs to source geometry.

Catalog totals for this build: 87 sharedassets files, 53,372 serialized objects, 5,210 meshes, 337 materials and 1,892 textures.
